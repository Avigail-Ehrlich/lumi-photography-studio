# MB Photographer

אתר תדמית רספונסיבי לצלמת, עם מקומות שמורים לתמונות ראשיות, תיק עבודות ותמונת הצלמת.

## דרישות

- Node.js 22.13 ומעלה
- npm

הפרויקט עובד ישירות ב-Windows, ב-macOS וב-Linux. אין צורך ב-Bash או ב-WSL.

## הפעלה ב-Windows

פתחי PowerShell בתיקיית הפרויקט והריצי:

```powershell
npm install
npm run dev
```

לאחר שהשרת עולה, פתחי בדפדפן את הכתובת שמוצגת במסוף.

## בניית גרסת Production

```powershell
npm run build
npm run start
```

## קבצים עיקריים

- `app/page.tsx` — מבנה ותוכן האתר
- `app/globals.css` — העיצוב וההתאמה למסכים שונים
- `app/layout.tsx` — הגדרות השפה והמטא-דאטה
- `public/` — המקום לקובצי התמונות והלוגו

## הוספת תמונות בהמשך

בשלב הנוכחי מופיעים באתר מקומות שמורים לתמונות בלבד. לאחר הוספת התמונות לתיקיית `public`, ניתן להחליף את אזורי ה-placeholder ברכיבי תמונה בתוך `app/page.tsx`.

## נגישות ופרטיות (התאמה לתקן — אוקטובר 2026)

האתר הותאם לתקנות שוויון זכויות לאנשים עם מוגבלות (התאמות נגישות לשירות), התשע״ג-2013, ולת״י 5568 ברמה AA, ולחוק הגנת הפרטיות, התשמ״א-1981.

**בפוטר, בשורה אחת:** לוגו | התאמות נגישות | הצהרת נגישות | מדיניות פרטיות | © 2026 MB Photographer. כל הזכויות שמורות | עיצוב ובנייה - {AJ}enda. במובייל — בטור, ממורכז.

- **התאמות נגישות** — חלון עם עצירת אנימציות, הגדלת טקסט, הדגשת קישורים ואיפוס. הבחירה נשמרת ב-localStorage (`a11y-settings`) ומופעלת כמחלקות `a11y-*` על `<html>`.
- **הצהרת נגישות** ו**מדיניות פרטיות** — נפתחות בחלון `<dialog>` צר (440px, עד 70% מגובה המסך, גלילה פנימית) במרכז המסך, באותו עמוד. נסגרות ב-Esc, בלחיצה מחוץ לחלון ובכפתור X.
- **תמיד פעיל:** סימון פוקוס בולט, וקישור "דילוג לתוכן" + כפתור "עצירת אנימציות" שמופיעים בלחיצה הראשונה על Tab. האתר מכבד גם את הגדרת "הפחתת תנועה" של מערכת ההפעלה.
- **רכזת נגישות:** מירית, 054-8520516.

קבצים: `components/legal-content.tsx` (תוכן ההצהרה והמדיניות), `components/legal-dialog.tsx`, `components/a11y-controls.tsx`, `lib/a11y.ts`, והעיצוב בסוף `app/globals.css`.

**לעדכן כשמשהו משתנה:** כשהטופס יחובר לשירות שליחה (כרגע הוא לא שולח לשום מקום), או כשיתווספו עוגיות, כלי סטטיסטיקה או שירות חיצוני — לעדכן את מדיניות הפרטיות ואת תאריך העדכון (`UPDATED` ב-`legal-content.tsx`).
